# Contributing

Thanks for your interest in CreateOS Sandbox. Here's how you can take part.

```
 you want to…                        do this
 ──────────────────────────────────  ─────────────────────────────────────────
 report a bug                        open an issue (anyone can)
 suggest a feature                   open an issue (anyone can)
 report a security problem           follow SECURITY.md (never an issue)
 get customization for createos.sh   contact us: enterprise route, below
 change the code                     maintainers only (see below)
```

## Issues are open to everyone

1. Search the [existing issues](https://github.com/NodeOps-app/createos-sandbox/issues)
   first. If someone already reported it, add a 👍 or a comment with new
   details instead of opening a duplicate.
2. Open a new issue with the **Bug report** or **Feature request** form, and
   fill in every field. Clear steps to reproduce get a bug fixed fastest.
3. Keep it to one problem per issue.

Don't put secrets in issues: no API keys, tokens, passwords, or private IP
addresses. Everything you post is public.

## Security problems are never issues

If you think you've found a security vulnerability, **don't open an issue.**
Report it privately as described in [SECURITY.md](SECURITY.md). Security
reports opened as public issues are removed.

## Pull requests are for maintainers only

This repository accepts pull requests only from its maintainers. GitHub blocks
pull requests from anyone else.

If you've found a fix, open an issue and describe the problem and your
proposed fix. Code snippets in the issue are welcome. A maintainer will pick
it up from there.

## Filing issues with an AI agent

Agents are welcome to file issues, under the same rules as people:

- A human reads every issue before it is posted, and stays accountable for it.
- Use the issue forms. Don't open blank or bulk-generated issues.
- Never post a security finding as an issue, even a "possible" one. Report it
  privately per [SECURITY.md](SECURITY.md).
- Include real reproduction steps you ran, not guesses about the code.

Low-effort, duplicate, or unverified agent issues are closed without reply.

## Enterprise and customization

We don't take requests for custom features, private deployments, SLAs, or
platform changes made just for you through issues. For anything specific to
your organization on <https://createos.sh>, contact us at
**[business@nodeops.xyz](mailto:business@nodeops.xyz)**.

## How this repository is maintained

The code here is synced weekly from the maintainers' development repository,
so the history in this repository starts fresh and pull requests made here
would be overwritten. Report problems through issues instead.
